# Emotion Detector Project

This project detects emotions in text using the Watson NLP emotion analysis service.

## Run the application

Install the dependencies:

```bash
pip install requests flask pylint
```

Run the tests:

```bash
python test_emotion_detection.py
```

Start the Flask server:

```bash
python server.py
```

Open http://127.0.0.1:5000 in a browser and enter text to analyze.
